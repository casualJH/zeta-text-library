# 제타 텍스트 보관함

제타(Zeta) 채팅에서 자주 쓰는 **OOC 지침, 유저 프로필, 프롬프트, 기타 텍스트**를 폴더별로 보관하고 복사하는 Tampermonkey 유저스크립트입니다. 저장된 보관함은 같은 사용자스크립트 저장 환경 안에서 여러 제타 채팅방에 공통으로 사용됩니다.

**현재 버전: 1.0.0**

## 설치

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/)를 설치하고 활성화합니다.
2. **[제타 텍스트 보관함 설치 / 업데이트](https://raw.githubusercontent.com/casualJH/zeta-text-library/main/zeta-text-library.user.js)** 링크를 열어 스크립트를 설치합니다.
3. [제타](https://zeta-ai.io/)에 접속하여 화면에 표시되는 보관함 실행 버튼을 누릅니다.

지원 대상 주소는 `https://zeta-ai.io/*` 및 `https://*.zeta-ai.io/*`입니다. 모바일 Safari에서 사용할 경우 Tampermonkey 확장 기능이 해당 사이트에서 활성화되어 있어야 합니다. 실제 동작은 브라우저 및 확장 프로그램 환경에 따라 달라질 수 있습니다.

## 주요 기능

- **텍스트 저장:** 제목과 본문을 작성하고 폴더를 지정해 저장·수정·삭제
- **기본 폴더:** `OOC`, `유저 프로필`; OOC의 하위 폴더 `요약`, `문체`
- **폴더 관리:** 상위·하위 폴더 추가, 이름 변경, 순서 변경 및 삭제
- **복사:** 개별 텍스트 복사, 여러 항목을 선택해 함께 복사
- **선택 작업:** 여러 텍스트를 한 번에 폴더 이동 또는 삭제(삭제 전 확인)
- **정렬:** 폴더순, 폴더순(역순), 등록순(오래된순), 등록순(최신순), 사용자 정렬
- **사용자 정렬:** 선택한 기준 순서로 시작한 뒤 드래그 손잡이(⠿)로 개별 또는 선택한 여러 항목의 순서를 조정
- **검색:** 제목 또는 본문으로 텍스트 찾기
- **화면 설정:** 기기 설정에 따르기 / 라이트 / 다크 테마, 상단 테마 전환 버튼, 실행 버튼 글자·크기 설정, 보관함 창 이동·크기 조절
- **백업 및 복원:** JSON으로 텍스트, 폴더, 정렬 기록, UI 설정 내보내기·가져오기

## 사용 방법

### 텍스트 추가 및 복사

보관함 하단의 **＋ 새 텍스트**에서 제목·본문·저장 폴더를 지정하여 저장합니다. 저장된 카드의 **복사** 버튼을 누르면 해당 본문을 복사할 수 있습니다. **수정**에서는 내용이나 폴더를 변경하고 삭제할 수 있습니다.

### 여러 텍스트 선택

하단 **선택** 버튼을 누르면 각 카드에 체크박스가 나타납니다. 필요한 항목을 체크한 뒤 다음 작업을 수행할 수 있습니다.

- **선택 복사:** 선택한 본문을 이어서 복사
- **폴더 이동:** 이동할 폴더를 지정하여 일괄 이동
- **선택 삭제:** 선택한 항목을 확인 후 일괄 삭제

선택 모드에서 선택된 항목의 드래그 손잡이를 끌면 여러 항목을 함께 이동할 수 있습니다. 드래그 정렬은 **사용자 정렬** 모드에서 사용합니다.

### 정렬 방식

**최상위 ‘전체’**의 최초 기본값은 **폴더순**입니다. **상위 폴더 안의 ‘전체’**는 최초에 **등록순(오래된순)**으로 표시됩니다. 사용자가 다른 정렬 방식을 선택하면 해당 위치의 선택이 저장됩니다.

| 정렬 | 표시 방식 |
| --- | --- |
| 폴더순 | 설정된 폴더 순서대로 표시 |
| 폴더순(역순) | 폴더 순서를 반대로 표시 |
| 등록순(오래된순) | 등록일이 오래된 항목부터 표시 |
| 등록순(최신순) | 최근 등록한 항목부터 표시 |
| 사용자 정렬 | 직접 지정한 순서대로 표시 |

**사용자 정렬**을 선택하면 **사용자 정렬 설정**에서 폴더순 또는 등록순을 초기 기준으로 지정할 수 있습니다. **기준 순서로 초기화**는 기존 드래그 순서를 덮어쓸 수 있으므로 확인창이 표시됩니다.

최상위 ‘전체’의 사용자 정렬과 각 폴더의 사용자 정렬은 독립적으로 보관됩니다. 폴더순 보기에서는 텍스트가 폴더별로 묶여 표시됩니다.

## 백업 및 복원

보관함의 **백업** 메뉴에서 JSON 백업 파일을 내려받거나 기존 백업 파일을 가져올 수 있습니다.

| 복원 방식 | 동작 |
| --- | --- |
| **기존 데이터 교체** | 현재 보관 내용을 백업의 폴더·텍스트·정렬 기록으로 교체합니다. 백업의 UI/정렬 설정도 복원합니다. |
| **기존 데이터에 합치기** | 현재 데이터 뒤에 백업 데이터를 추가합니다. 기존 UI/정렬 방식 설정은 유지합니다. |

> **합치기 주의:** 현재 구현은 이름이나 내용을 기준으로 중복 제거하지 않습니다. 기존 폴더와 같은 이름의 폴더가 다시 만들어지거나 동일한 텍스트가 중복 추가될 수 있습니다. 등록순으로 표시할 때는 기존 데이터와 추가한 데이터가 등록일 기준으로 섞일 수 있습니다. 합치기 전에 JSON 백업을 따로 보관하는 것을 권장합니다.

텍스트의 등록일(`createdAt`), 사용자 정렬 순서(`orders`), 정렬 방식 및 기준(`sortModes`, `sortBases`)이 백업 데이터에 포함됩니다.

## 데이터 저장과 주의사항

보관함 데이터는 서버에 업로드하는 방식이 아닌 **Tampermonkey 저장소(`GM_getValue` / `GM_setValue`)**를 통해 보관됩니다. 사용자스크립트 저장 데이터가 유지되면 브라우저를 다시 열어도 텍스트·정렬 설정이 유지됩니다. 다만 브라우저 데이터나 확장 프로그램 데이터를 삭제하거나 다른 기기로 옮기는 경우에는 자동으로 동기화되지 않으므로 JSON 백업을 사용하세요.

- **폴더 삭제:** 해당 폴더에 있던 텍스트는 미분류로 이동합니다.
- **텍스트 삭제/전체 초기화:** 삭제한 데이터는 별도 백업이 없으면 복구할 수 없습니다.
- **대량 데이터:** 항목이 많거나 본문이 길면 브라우저 성능 및 확장 프로그램 저장 용량의 영향을 받을 수 있습니다.
- **이미지:** 텍스트 전용 보관함으로, 이미지 저장·이미지 붙여넣기 기능은 제공하지 않습니다.
